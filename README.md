# Dental Clinic Pro — Demo

ديمو أولي لموقع عيادة أسنان عربي RTL، مصمم للبيع والتخصيص لعيادات الأسنان.

## المحتوى
- الصفحة الرئيسية
- الخدمات
- من نحن
- آراء المرضى
- حجز موعد
- WhatsApp
- التواصل والموقع
- تصميم Responsive للموبايل والكمبيوتر

## التخصيص
غيّر اسم العيادة، الشعار، رقم WhatsApp، العنوان، الصور، الخدمات، وآراء المرضى داخل `index.html`.
